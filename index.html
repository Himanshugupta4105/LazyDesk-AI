Quick start guide

Complete these steps on your computer before using local AI.

  1. Install Ollama

    Download it from ollama.com/download.

  2. Download a model 
    ollama pull qwen2.5:3b
  3. Check installed models 
    ollama list
  4. Start Ollama

    Ensure Ollama is running before testing the connection.

  5. Open LazyDesk locally

    Use a local development server if your browser blocks requests from a file URL. Configure allowed origins if necessary.
